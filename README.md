# KOIN Recode Project

KOIN 은 [한국기술교육대학교(KOREATECH)](https://www.koreatech.ac.kr/) 학생들을 위한 캠퍼스 서비스입니다.

시간표, 버스, 식당, 가게, 커뮤니티, 동아리, 분실물, 졸업 계산기 등을 제공합니다.

## 왜 만들었나

한국기술교육대학교는 도심에서 떨어진 병천면에 있다 보니, 도심 상권 위주로 나온 서비스를 그대로 쓰기가 애매합니다.

그래서 학생들이 직접 쓸 수 있는 서비스를 만들었습니다.

## 기술 스택

- UI 라이브러리/프레임워크
  - [React 19](https://reactjs.org/docs/hello-world.html)
  - [Next.js 15 (Pages Router)](https://nextjs.org/docs)
- 언어
  - [TypeScript](https://www.typescriptlang.org/) (strict mode)
- 패키지 매니저
  - [Yarn 4 (Berry) PnP](https://yarnpkg.com/), Zero-Install
- 서버 상태 관리 라이브러리
  - [React Query (TanStack Query v5)](https://tanstack.com/query/latest)
- 클라이언트 상태 관리 라이브러리
  - [Zustand](https://github.com/pmndrs/zustand)
- 린팅 라이브러리
  - [ESLint](https://eslint.org/docs/latest/user-guide/getting-started)
  - [Stylelint](https://stylelint.io/)
- 스타일링 라이브러리
  - [Sass](https://sass-lang.com/guide)
  - [BEM style](http://getbem.com/introduction/)
  - [CSS Modules](https://github.com/css-modules/css-modules)
